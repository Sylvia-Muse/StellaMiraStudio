# demos/

## particle-mv.html

一个**单文件**的粒子 MV 播放器：拖一首音频进去，画面会跟着音乐的频谱与能量变化，
配合时间轴字幕显示歌词。

- 纯前端，无构建、无依赖（three.js 已内联），双击打开即用
- 音频**不在文件里**——页面上有「DROP AUDIO FILE」区域，把 mp3/wav 拖进去即可
- 字幕时间轴是一份 `[秒, 英文, 中文]` 的数组，改数组就能换成你自己的词

> 本仓库里所有歌词文本已替换为占位符（`♪` / `（示例歌词）`），
> 演示用的原曲不随仓库分发。想做成片请自备**有授权的**音轨与歌词。

做法笔记（也见 `docs/制作方法论.md`）：

- 粒子层用 canvas 叠加，能量决定粒子速度与亮度，低频决定扩散半径
- 字幕按数组里的时间点切换，中间用淡入淡出，不做逐字动画——MV 里字太多会抢画面
