# ink-glyph-scroll · 长卷水墨 MV 演示

一支「**把歌词当书法写在一张横卷上**」的 MV 渲染器。每句词整句写出来、写完**留在纸上不擦**，卷面在句末缓缓推进；唱到最后整首词都在纸上，然后散尽。

1080p / 30fps / 确定性（同一 `t` 永远同一帧，可任意 seek、可逐帧抓成视频）。

## 它解决的三个问题（都是踩出来的）

**1. 墨不像墨，像沙**
均匀小点按 alpha 叠加，调任何参数都只能是沙。这里改成：粒子累加进一张 **RGBA16F 密度场**，合成时用 `1-exp(-k·d)` 映射成墨色 —— 重叠自然变浓；横截面 `(1-r²)^0.85` 让笔腹厚、笔缘薄；湿边与飞白从中浓度区里算出来，不贴图。

**2. 笔锋是假的**
骨架化（Zhang-Suen）后按笔顺合并回笔画，**距离变换取局部半宽当笔压**。注意：距离变换要把掩码像素**初始化成最大值**，否则算出来的是"背景到字形"的距离，笔压恒为 0（这个 bug 我踩了整整一轮，笔锋从没生效过）。

**3. 一镜一字没人看**
60 句写 60 个单字、镜头不动 = 观众看两句就腻。改成**长卷累积**：字留下、卷移动、取景按乐句推拉。相机关键帧要**给器乐段也铺上**——只按歌词行生成的话，间奏没有行就没有关键帧，相机会原地不动 18 秒。

## 跑起来

```bash
cd demos/ink-glyph-scroll
python3 -m http.server 8090   # 注意要在这个目录起，art/ 是相对路径
# 打开 http://127.0.0.1:8090
```

默认读 `manifest.sample.json` + `beats.sample.json`（占位数据，只为让页面能跑）。
正式用请把自己的数据挂上去：

```html
<script>window.MANIFEST='my-manifest.json'; window.BEATS='my-beats.json';</script>
```

## 数据契约

`manifest.json`
```json
{ "duration": 171.58,
  "lrc": [ { "t": 16.45, "end": 18.60, "text": "第一句" } ] }
```
- `t` 必须是**在自己这条音轨上实测**的，不是官方 LRC 的原始时间
- `end` 建议按「下一行 − 0.05，最多挂 5.5 秒」推

`beats.json`
```json
{ "fps": 30, "full": [...], "bass": [...], "onset": [...] }
```
每帧一个 0..1 的值，长度 = 时长 × fps。

## 抓成视频

```bash
python3 ../../tools/视频自检/../mv_capture_page.py ...   # 我们私用的脚本没放进来
```
通用做法：`page.evaluate('window.__seek(t)')` → 截图 PNG → ffmpeg 拼 + 混音。
**注意 `__seek` 必须从 0 预热到 t**（缓动有状态），否则形状只走一步。

## 自检

```bash
python3 check_overflow.py 你的成片.mp4            # 出画检查：墨迹有没碰到左右边缘 3%
python3 check_overflow.py 你的成片.mp4 --thr 170  # 暗角重时压低阈值
```

判据：**越界帧 ≤ 2/80 且越界宽度 < 画面宽 1%**；越界像素还要够淡（中位 alpha < 0.35、无 alpha > 0.6 的实墨）。

> ⚠️ 阈值别用默认 200：暗角会把纸压到约 199，用 200 会把整圈暗角判成墨（我第一次跑就是 79/80 全红）。

## 素材是纯代码生成的

`build_art_assets.py` 从系统字体出发：渲染 → 阈值 → 细化 → 骨架合并 → 笔顺 → 距离变换取笔压，产出 `art/glyphs.json`（每点 `[x, y, 法线, 笔压, 书写进度u]`）。

**没有用任何绘图模型**。这是刻意的：素材可验证、可复现、不依赖第三方。
