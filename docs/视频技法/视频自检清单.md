## 0. 规格（30 秒能过）

- [ ] **画幅 / 帧率 / 时长对**
  ```bash
  ~/bin/ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate,nb_frames \
    -show_entries format=duration -of default=nw=1 "$V"
  ```
  判据：横屏 `1920x1080`、竖屏 `1080x1920`；`30/1`；时长与设计稿一致（±0.1s）。

- [ ] **有音轨，且是 48kHz 立体声**
  ```bash
  ~/bin/ffprobe -v error -select_streams a:0 -show_entries stream=codec_name,sample_rate,channels \
    -of default=nw=1 "$V"
  ```
  判据：`aac / 48000 / 2`（MV 可 `2`，口播 `2`）。

- [ ] **没有意外黑场 / 冻结帧**
  ```bash
  ~/bin/ffmpeg -nostdin -i "$V" -vf "blackdetect=d=0.5:pix_th=0.10,freezedetect=n=0.003:d=2" \
    -an -f null - 2>&1 | grep -E "black_start|freeze_start" || echo "无黑场/冻结"
  ```
  判据：无输出（有意的黑场要事先登记）。

## A. 镜头与节奏

- [ ] **A1 最长静止段 ≤ 2.5s**
  ```bash
  $PY scripts/vshot_report.py "$V" --profile mv | grep "最长静止段"
  ```
  判据：`[PASS]`。水墨/静帧动画内容如果帧差整体偏小，加 `--auto-static`。

- [ ] **A2 静止段**：最长单次 ≤ 3s，且不连续出现
  ```bash
  $PY scripts/vshot_report.py "$V" --profile mv | sed -n '/C1\/C2/,/C3/p'
  ```
  判据（两条都要过，脚本直接给 `[PASS]/[FAIL]`）：
  1. `最长静止段 ≤ 3.0s`；
  2. `最长连续静止串 ≤ 3.0s`——两条静止之间隔着的**非静止**时长 < **0.20s** 才算连着，
     连成的串总长也不得超 3.0s。

  > **为什么把判据从"静止占比 ≤ 18%"换成这条**（2026-11-02 修订）：
  > 原来的"占比"判据和**真实的观感无关**。
  > 改版后的镜头是「快速到位（0.38s）+ 停住」，停住的那段帧差天然很低，
  > 于是占比必然偏高（实测 19–20%）——但观众看到的是"镜头一次次到位"，不是"片子卡住了"。
  > 反过来说，老版 MV 的占比也是 19%，却是**一段连续 12.7s 死住**，观感完全不同。
  > **占比量的是"总量"，观感取决于"最长一次"和"是不是连着"**，所以改判据不改片子。
  >
  > **间隔阈值为什么是 0.20s 而不是 1.0s**：我们的运镜最短是 0.38s 的"快速到位"。
  > 阈值取 1.0s 会把每次到位都当成"没动"，一轮「停 2s + 推 0.38s」重复 4 次就被并成
  > 8.7s 的"连续静止"——那是假阳性，观众看到的是镜头一次次到位。
  > 阈值必须**小于任何一次有意的运镜**。实测：1.0s → 8.7s（假阳性）；0.20s → 2.3s（与观感一致）。
  > 改版后：最长单次 2.3s、无连续串，过；老版：最长单次 12.7s，不过。

- [ ] **A3 最长"一个取景" ≤ 12s（MV）/ ≤ 6s（严格档）**
  ```bash
  $PY scripts/vshot_report.py "$V" --profile mv | grep "最长一个取景"
  ```
  判据：`[PASS]`。这条抓的就是"一镜到底"。

- [ ] **A4 景别动态范围 ≥ 2.5×（MV）/ ≥ 1.5×（竖屏）**
  ```bash
  $PY scripts/vshot_report.py "$V" --profile mv | grep "景别动态范围"
  ```
  判据：`[PASS]`。这是"好不好看"里最硬的一条。

- [ ] **A5 逐镜头景别序列，相邻不同档**
  ```bash
  # 先用 build 脚本导出剪辑点表 cuts.txt（一行一个秒数），再：
  $PY scripts/vshot_report.py "$V" --cuts cuts.txt --profile mv
  ```
  判据：`相邻镜头同景别 ≤ 1 次`；脚本会把整条景别序列打出来
  （`1:近景@38%  2:特写@52% ...`），人工再看一遍有没有连续三镜同档。

- [ ] **A6 每个剪辑点都落在拍上（±1 帧）**
  ```bash
  $PY - <<'PY'
  import json, itertools
  m = json.load(open("data/videos/<工程>/manifest.json"))
  beats = [b[0] if isinstance(b, (list, tuple)) else b for b in m["beat_times"]]
  cuts  = [float(x) for x in open("cuts.txt") if x.strip()]
  for c in cuts:
      d = min(abs(c - b) for b in beats)
      print(f"{c:7.2f}s  离最近拍 {1000*d:6.1f} ms  {'OK' if d <= 0.033 else 'FAIL'}")
  PY
  ```
  判据：全部 `OK`（无 beat_times 的片子跳过本条，改用 `--reframe-lum` 视觉复核）。

- [ ] **A7 每 10s 至少 2 次"大事件"**
  ```bash
  $PY scripts/vshot_report.py "$V" --profile mv | grep "取景变化点"
  ```
  判据：`取景变化点 / (时长/10) ≥ 2`。

## B. 画面

- [ ] **B1 黑位 / 白位 / 动态范围 / 中位亮度**
  ```bash
  $PY scripts/vtone_check.py "$V" --profile water-ink      # 水墨
  $PY scripts/vtone_check.py "$V" --profile person         # 人像
  ```
  判据：`黑位 P0.1 ≤ 35`、`白位 P99.5 ≥ 225`、`动态范围 ≥ 150`、`中位亮度 P50 ∈ 190–235`
  四项全 `[PASS]`。

  > **为什么黑位用 P0.1 而不是 P0.5**（2026-11-02 修订，经实测确认）：
  > 「**有没有黑**」和「**黑有多少**」是两件事，之前的 `P0.5 ≤ 45` 实际在量后者。
  >
  > `【实测·本片】` v4 样片分档：**P0.1% = 21**（纯黑）、P0.2% = 51、**P0.5% = 62**、P1% = 72。
  > 墨芯明明是 21 的纯黑，但黑的部分只占画面 0.1–0.5%，于是 P0.5 判据判它"没有黑"——错判。
  >
  > 而且「黑有多少」已经由 **B2 暗部面积 ≥ 2%** 独立管着，两条判据在**重复计分**，
  > 且 `P0.5` 对「只有一行字是实墨、其余全是淡干墨」的水墨构图天然不友好。
  >
  > 所以拆开：**B1 的 `黑位 P0.1` 量"有没有黑"，B2 的 `暗部面积` 量"黑有多少"。**
  > 改判据不改片子：v4 在旧判据下 `P0.5=62` 不过、在新判据下 `P0.1=21` 通过，两者对同一帧
  > 的描述并不矛盾，只是量的东西不同。

- [ ] **B2 暗部面积 ≥ 2%（水墨）**
  ```bash
  $PY scripts/vtone_check.py "$V" --profile water-ink | grep "暗部面积"
  ```
  判据：`[PASS]`。这条直接对应"画面发灰、墨没有重量"。

- [ ] **B3 没有大于 4/255 的硬横向断层（纸纹 clamp / 图层接缝）**
  ```bash
  $PY - "$V" <<'PY'
  import statistics, subprocess, sys
  from PIL import Image
  V = sys.argv[1]
  subprocess.run(["/opt/homebrew/bin/ffmpeg","-v","error","-y","-ss","5","-i",V,
                  "-frames:v","1","-pix_fmt","gray","/tmp/_seam.png"], check=True)
  im = Image.open("/tmp/_seam.png").convert("L"); W,H = im.size; px = im.load()
  worst = []
  for xa,xb in [(40,W//3),(W//3,2*W//3),(2*W//3,W-40)]:
      meds=[]
      for y in range(20,H-20,4):
          meds.append((y, statistics.median([px[x,y] for x in range(xa,xb,7)])))
      for i in range(8,len(meds)-8):
          a = statistics.median([m[1] for m in meds[i-8:i]])
          b = statistics.median([m[1] for m in meds[i:i+8]])
          if abs(b-a) >= 4: worst.append((meds[i][0]/H, b-a))
  print("硬横向断层:", worst[:6] if worst else "无")
  print("判据: 无 |d|>=4 的孤立台阶 ->", "PASS" if not worst else "FAIL")
  PY
  ```
  判据：`PASS`。对多个时间点（0s/5s/中段/结尾）各跑一次。

- [ ] **B5 顶部不留半截字（顶边裁切帧 ≤ 5%）**
  ```bash
  $PY - "$V" <<'PY'
  import sys; sys.path.insert(0,'scripts')
  import vcommon as V
  aw, ah = 320, 180; top = n = 0; worst = 0.0
  for fr in V.gray_frames(sys.argv[1], aw, ah, 4.0):
      n += 1
      prof = V.row_profile(fr, aw, ah, 170, above=False)
      hit = [y for y in range(ah) if prof[y] >= 3]
      if hit and hit[0] == 0:
          k = 0
          for y in range(ah):
              if prof[y] >= 3: k += 1
              else: break
          top += 1; worst = max(worst, k / ah)
  print("采样 %d 帧，顶边贴墨 %d 帧 (%.0f%%)，最深被切 %.1f%% 画面高"
        % (n, top, 100 * top / n, worst * 100))
  print("判据 顶边贴墨帧 <=5% ->", "PASS" if top / n <= 0.05 else "FAIL")
  PY
  ```
  判据：`PASS`。暗底素材把 `above=False` 改成 `above=True`。
