# ink-particles

**确定性的 WebGL2 粒子系统**——专门用来做"墨"这种流体质感，但设计上只服务一件事：

> **同一时刻 `t`，永远渲染出同一帧。**

无依赖、单文件 ES module、WebGL2。

## 为什么强调"确定性"

做 MV 要逐帧抓成视频。常见的粒子系统按帧累加状态（`pos += vel * dt`），一旦：

- 截图慢了（每帧 0.1~0.4 秒）→ 动画比音乐快 3 倍
- 想拖进度条回看 → 回不到同一帧
- 想并行渲染 → 两台机器结果不一样

**本库所有运动都是在顶点着色器里由 `t` 解析计算的**：没有状态累积，`dt` 不参与运算。
所以任意 seek、任意帧率、任意机器，第 12.5 秒永远是同一张图。

## 快跑

```bash
cd demo
python3 make-textures.py      # 生成墨点与纸纹（纯程序纹理，不调用任何绘图模型）
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

```js
import { InkParticles } from '../src/ink-particles.js';

const p = new InkParticles(canvas, {
  count: 80000,          // 粒子数（8 万在中端 GPU 上很轻）
  ink: 'ink-dot.png',    // 墨点贴图
  paper: 'paper.png',    // 纸纹（可选）
  size: 0.010,           // 尺寸（相对画布高度）
  spread: 0.8,           // 扩散半径
  flow: 1.0, curl: 1.6,  // 流动与卷曲
  alpha: 0.5,
});

await p.ready;
p.setTime(12.5).render();   // 抓帧就这一句

// 跟着音乐能量调参
p.set({ spread: 0.8 + level * 0.3, alpha: 0.45 + level * 0.2 }).render();
```

## 沿笔迹分布（`setPath`）

默认是"径向墨团"。想做**水墨的线**，就给一条路径——粒子会沿着它分布，边缘自然散成飞白：

```js
import { personPath } from './demo/paths.js';   // 或者自己给一串点

p.setPath(personPath(), 0.028);   // 归一化坐标 + 笔画粗细
p.set({ alpha: 0.9, size: 0.020, curl: 1.1 });
```

- 点用归一化坐标（0..1），按顺序连成折线，内部等距重采样成 1024 个点写进浮点纹理
- 法线方向做**中间密、两边稀**的偏移（`pow(|off|, 2.2)`），所以笔画有中心、有毛边
- `p.clearPath()` 回到径向墨团

这条路径可以来自任何地方：手写的点、SVG 轮廓采样、或者图像边缘提取。

### 从一张图提取路径

```bash
python3 tools/edge-path.py 蝶.png die-path.json
# 输出 {"size":[w,h], "points":[[x,y],...]}  ← 归一化坐标，直接喂 setPath
```

算法很朴素：阈值取墨 → 网格降采样 → 贪心最近邻串成折线。
不追求精确描边，追求"像一笔一笔画上去的"。画得越清楚，路径越像。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `count` | 60000 | 粒子数 |
| `ink` | — | 墨点贴图；不给就是纯圆点 |
| `paper` | — | 纸纹；不给就是纯色底 |
| `color` | `[.11,.086,.063]` | 墨色（默认是偏暖的黑） |
| `size` | 0.012 | 点尺寸，相对画布高度 |
| `spread` | 0.75 | 扩散半径 |
| `center` | `[.5,.5]` | 团的中心（归一化） |
| `flow` / `curl` | 1.0 / 1.4 | 流动速度 / 卷曲程度 |
| `alpha` | 0.55 | 整体透明度 |
| `vignette` | 0.25 | 暗角 |
| `thickness` | 0.03 | 笔迹模式下笔画粗细（相对画布短边） |

## 实现要点

- **curl noise**：对势场取旋度得到无散度场，粒子不会聚成团、也不会凭空消失
- **种子固定**：粒子种子用线性同余生成器（LCG），不同浏览器得到同一组种子
- **点精灵 + 贴图**：每个粒子贴一张墨点，用 `gl_PointCoord` 采样，圆形裁剪
- **两段渲染**：粒子先画到离屏 FBO（保留 alpha），再和纸底合成——这样墨色能正确叠在纸上
